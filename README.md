# SIDHGAN JEWELLERS Website (HTML + CSS + JavaScript)

Ye project aapki jewellery firm ke liye advanced ecommerce-style single page website hai.

## Included Features
- Responsive premium UI
- Product catalogue with search + category filters
- WhatsApp inquiry per product
- Direct call buttons
- Hallmark / Kundan / Jadau / Modern / Traditional details
- Product management form (browser se product add)
- JSON export/copy for Blogger integration

## Add Your Own Logo
- Apna edited logo `assets/logo.png` path par rakhein.

## Add Your Own Jewellery Images
- `app.js` ke `defaultProducts` mein `image` URLs replace karein.
- Ya website ke "Manage Products" section se directly product add karein.

## Update Contact Details
`app.js` me `FIRM` object update karein:
- `whatsappNumber`
- `callNumber`

## Blogger Integration (Simple)
1. Site ka HTML/CSS/JS copy karein.
2. Blogger page/post me HTML mode open karein.
3. Products JSON ko script/json ya widget data ke roop me paste karein.
4. Agar chahen to alag static hosting se script load kar sakte hain.

## Run
Direct `index.html` browser me open karein.
